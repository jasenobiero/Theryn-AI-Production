name: THERYN interface direction
description: The product-level visual direction for THERYN across web and mobile.
---

THERYN uses a strict monochrome identity: the network-node mark has no baked-in background and uses black in light mode and white in dark mode. Keep interface details monochrome, avoid neon accents, and use restrained grayscale animation across desktop and mobile.

**Why:** The user supplied the official network-node mark and specified that its background must remain transparent, with its color adapting to light or dark mode.

**How to apply:** Use the same transparent, theme-aware mark on web and mobile. Keep generated images in their original colors; do not recolor user-generated content.
