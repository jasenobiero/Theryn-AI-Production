name: THERYN interface direction
description: The product-level visual direction for THERYN across web and mobile.
---

THERYN uses a strict monochrome identity: the user's black network-node mark on white, black-and-white interface details, no neon accents, and restrained grayscale animation across desktop and mobile.

**Why:** The user asked for a futuristic, original AI product, then provided the official black-on-white logo and explicitly asked the interface to match it.

**How to apply:** Use the same monochrome node mark and grayscale motion on web and mobile. Keep generated images in their original colors; do not recolor user-generated content.
